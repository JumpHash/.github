## `00` Thesis

**Boring on purpose.**

```md
# THESIS.md
We design, build and operate software and hardware that behave the same way every time.

## what we believe
Software should be boring. Excitement is what incidents feel like.
Same input, same output. On a Tuesday, at 3 a.m., during a demo.
If it can't be reproduced, it didn't happen.

## how we work
Measure first. Opinions are cheap; flame graphs are cheaper.
Every incident ends with a postmortem and a smaller system.
'It works on my machine.' We ship the machine.

## eof
Small machinery, verified behaviour, boring on purpose.
```

## `02` Open source

<a href="https://github.com/JumpHash/agentplaza">
  <img alt="AgentPlaza: your AI agents, governed. Each agent in its own microVM, held to laws you write and paid from a budget you control." src="https://raw.githubusercontent.com/JumpHash/.github/main/profile/assets/agentplaza.png" width="100%">
</a>

**[AgentPlaza](https://github.com/JumpHash/agentplaza)** runs self-hosted AI agents, each sealed in its own microVM with no network interface. A hub on your own machine checks every tool call against laws you write, keeps provider keys in a vault the agents never see, pays each agent from a budget, and holds everything at once with one STOP ALL button. Written in Rust, for Linux, macOS, Windows and Raspberry Pi.
